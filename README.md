## 🩺 Doctor Appointment Booking Web Application

A responsive web application that allows users to browse doctor profiles, view their availability, and book appointments. Built using React.js and class-based components without React Hooks.



## 🚀 Features

- View a list of doctors with specialization, availability, and profile picture
- Search doctors by specialization
- View detailed doctor profiles including weekly availability
- Book appointments through a simple form



## 🛠 Tools & Libraries Used

1.React Js - UI development
2.React Router V5 - Client-side routing
3.JavaScript
4.HTML/CSS - Layout and basic styling
5.Mock JSON

## 🧠 Challenges Faced & Solutions

### 1. **Avoiding State Management Libraries**
> **Challenge:** Needed to manage state transitions (search filter, booking form) without Redux or Context.
>
> **Solution:** Handled local component state using class-based state management (`this.state`, `this.setState`) in each relevant component.
